Generate each set with the same voice and settings as the original reference clips, then save as
`reference/engineer_voice6.mp3`, `engineer_voice7.mp3`, … (one file per set).
Numbers are written as words on purpose, so the generator reads them exactly as the app will.

Sets 1–7 contain every full radio line in `manifest.json`. Sets 8–10 drill the stitched templates
(prefix + number + suffix) with a spread of integers and decimals.
