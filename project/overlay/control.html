F1 Overlay Control

HUDs (turn each one on / off)
● on · ○ off. Hotkeys: Ctrl+Alt+H (all), T, K, G, O, F, V, L.
Mode and edit
Pause the game from its own menu, enter edit mode, drag the HUDs, then leave with Esc (or the same button).
Halo position
Drive with the halo in clear view (no menu over it), then press the button or Ctrl+Alt+A: the overlay finds your halo on screen and saves the position and size for this team. A team without its own profile is fitted automatically the first time you drive it. Start the game or the demo, turn the halo on and adjust it here. Position and this size are saved per team.
Size of each HUD These sizes apply at any resolution and are saved. The overall halo size multiplies the team size above. 1× is the original size.
